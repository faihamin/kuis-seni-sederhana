# 🎭 Kuis Seni Tari

Aplikasi kuis interaktif untuk menguji pengetahuan tentang seni tari tradisional Indonesia.

## ✨ Fitur Utama

- 📝 Input Nama - Pengguna memasukkan nama sebelum mulai
- 🎯 Kuis Interaktif - Pertanyaan acak tentang seni tari
- 🏆 Sistem Penilaian - Skor otomatis setelah menjawab
- 📊 Skor Tertinggi - Lihat peringkat tertinggi
- 🗑️ Hapus Data - Reset skor kapan saja

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 🚀 Cara Pakai

1. Clone repository ini
2. Buka `index.html` di browser
